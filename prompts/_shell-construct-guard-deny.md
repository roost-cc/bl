Write a small script in your scratch dir (`node <file>.mjs` or `python3 <file>.py`) and run it; loops, variables and command substitution (`$(…)`, backticks) are denied in headless sessions. Repeat a path literally instead of putting it in a variable. For a commit message, write it to a file and use `git commit -F <file>`. If a `$(` or backtick is meant literally (a search pattern, a message), put it in single quotes.
