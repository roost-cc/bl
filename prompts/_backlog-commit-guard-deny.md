Don't commit the backlog repo without a pathspec or with `-a` / `--all` or `-i` / `--include`. Every session shares the backlog's working tree and index. Such a commit takes along whatever other sessions have staged at that moment and files it under your message. Commit backlog edits with `bl sync --commit -m "<msg>" --story <id> [--path <backlog-relative path>]`. It takes the backlog lock, commits only the story's directory and the paths you name, and pushes. For a path `bl sync` can't name, commit by path: `git -C {{backlogRoot}} commit -m "<msg>" -- <paths>`.
