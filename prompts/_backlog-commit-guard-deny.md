Don't commit the backlog repo without a pathspec or with `-a` / `--all` or `-i` / `--include`. Every session shares the backlog's working tree and index, so such a commit takes along whatever other sessions have staged at that moment and files it under your message. Commit backlog edits with `bl sync --commit -m "<msg>" --story <id> [--path <backlog-relative path>]`: it takes the backlog lock and commits only the story's directory, the paths you name and the index files it regenerates. For a path `bl sync` can't name, commit by path: `git -C {{backlogRoot}} commit -m "<msg>" -- <paths>`.
